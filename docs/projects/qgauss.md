# QGauss AI

**把多模型对话与多模态创作放进同一个自托管工作空间。** 面向个人创作者和小型 AI 站点运营者，同时提供创作体验与账户、渠道、权益、订单及维护工具。

## 功能与技术

后端使用 NestJS、TypeScript、Prisma 与 SQLite；前端使用 Vue、Pinia、Rollup 和 Element Plus。工作空间覆盖流式对话、附件、分支与重新生成、联网检索、图像创作和选区编辑、视频、声音记录与朗读、思维导图、自建应用及扩展画布。

运营端管理模型渠道、会员与次数权益、订单、卡密、分销、邮件回执和加密备份。作品可以收藏、公开、撤回，并把允许复用的提示词与参数带回创作台。三套视觉主题覆盖玻璃、光影与动效偏好。

## 上手路径

从仓库克隆源码后运行：

```bash
npm ci
npm run setup:guided
npm run serve:prod
```

打开 `http://127.0.0.1:9520/setup`，用本机安装凭证创建首位管理员，再配置模型渠道与站点参数。开发用的模拟模型与演示账户走单独路径，不自动写进生产安装。真实模型、邮件和商户能力需要部署者分别配置与验证。

## 迭代中解决的难题

- **流式回答与费用脱节：** 把接受请求、预留次数、保存结果与最终结算拆为持久阶段；用事务和状态条件防止重试、取消或重启造成重复扣费。已保存的完成结果可以继续结算，已中断的上游流不伪装成恢复成功。
- **单机并发等待：** SQLite 写事务在单进程内排队，避免低核数环境中等待数据库锁的连接占满执行线程；模型生成和邮件投递放在事务外。
- **页面与账号边界：** 身份变化或页面离开后丢弃失效响应；个人文件与作品按所属账户授权，避免迟到操作进入另一个账号。
- **创作恢复：** 作品复用、图像选区、扩展提问与恢复沿用原操作回执；重复点击、查看和带入参数不额外创建生成任务。需要替换既有草稿时明确确认。
- **公开与私有内容：** 自建角色默认私有，发布经审核，撤回和回收停止新的公开使用；声音清理停止内容读取，但保留费用回执。
- **部署完整性：** 首次安装不覆盖现有环境配置，缺少强密钥时拒绝启动；生产包不分发源码映射，旧入口保留参数并提供失败恢复。

## 范围

当前数据库、任务调度和恢复机制按单实例验证。多实例、外部存储、真实模型效果、商户收款、外部收信、生产负载与离机恢复需独立验收。本地模拟服务测试证明对应行为，不等于这些外部链路已经投入商用。

早期 QGauss 的多模型接入、校园用户定位、次数与订阅定价、反馈和社群增长属于本人履历中的产品孵化经历；不把早期 API 接入数量当成当前部署环境的可用模型数量。
